# Proyecto FullStack - ToDoApp 📑

Aplicación de gestión de tareas (ToDo) completa con sistema de autenticación de usuarios. Permite crear, gestionar y marcar tareas como completadas con una interfaz moderna y responsiva.

## Características

- **Sistema de autenticación**: Registro de usuarios con validación de email y contraseña
- **Login seguro**: Autenticación con JWT y cookies httpOnly
- **Gestión de tareas**: Crear, eliminar y marcar tareas como completadas
- **Validación de email**: Integración con Abstract API para verificar emails válidos
- **Interfaz responsiva**: Diseño adaptable a móviles y escritorio
- **Contador de tareas**: Visualización de total, completadas y pendientes

## Tecnologías

### Backend
- Node.js
- Express.js
- MongoDB con Mongoose
- JWT para autenticación
- Bcrypt para encriptación de contraseñas
- Nodemailer (configurado pero desactivado)
- Abstract API (validación de email)

### Frontend
- Vanilla JavaScript
- Tailwind CSS para estilos
- Axios para peticiones HTTP
- Diseño responsivo
